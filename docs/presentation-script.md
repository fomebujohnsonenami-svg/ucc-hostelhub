# University demonstration script

## Before the session

Use the isolated presentation project, load the [fictional dataset](deployment.md), and verify the [feature checklist](feature-checklist.md). Have separate browser profiles ready for the Demo Student, Demo Manager and administrator. Keep their passwords off screen. Add a fictional image to Demo Atlantic View Hostel through the manager photos page, and confirm there is a visible roommate profile and at least one inquiry.

| Step | Presenter action |
| --- | --- |
| 1 | Open the landing page. Introduce UCC Hostel Hub as a student accommodation discovery and management platform. |
| 2 | Open **Hostels**. Point out the five **Demo** listings and explain that they are fictional. |
| 3 | Filter by **Amamoma**, a semester price up to **GH₵1,000**, and available beds. Open **Demo Atlantic View Hostel**. |
| 4 | Show the card image if uploaded, semester rates, amenities and when the manager last confirmed the count. |
| 5 | Choose **Get Directions**. Explain that it shows a public UCC-area demonstration point. Return to the listing. |
| 6 | Sign in as **Demo Student**. Open **Saved Hostels** and show the seeded favourite. |
| 7 | Open **Find Roommate** and view **Demo Roommate**. Explain budget overlap, area and shared preferences. |
| 8 | Open **Messages** or **Contact Manager** on Atlantic View. Send a short inquiry and show where a reply arrives. |
| 9 | Switch to the **Demo Manager** browser profile. Open and reply to the inquiry. |
| 10 | Open **Availability**, select the Atlantic View double room and confirm a different bed count. Refresh the student listing to show the updated count. |
| 11 | Open **Hostel Promotion**, then choose **Upgrade to Premium** and show **Payments coming soon**. |
| 12 | Switch to the administrator browser profile. Show platform counts, manager verification, listing suspension and report moderation. |

Recheck prices and filters if the demo records were edited during rehearsal. Keep **Help & Support** ready to verify the Django connection if a step stalls.
